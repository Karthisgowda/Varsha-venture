GitHub Pages cannot store enquiries from every phone and laptop by itself. Add a real Firebase web config in firebase-config.js, then enable Firestore and Storage.

  1. Create a Firebase web app and copy its config values.
  2. Paste the values into firebase-config.js.
  3. Enable Cloud Firestore and Firebase Storage.
  4. Use the rules from FIREBASE_SETUP.md, then push the site again.
