# Launch Checklist

Use this checklist before treating the site as complete and ready for real customers.

## Pre-launch

- Confirm brand name, logo, contact email, phone number, and address.
- Confirm all loan products are accurate.
- Confirm document requirements for salaried and self-employed customers.
- Confirm privacy policy and terms are published.
- Confirm admin password is not shared publicly.
- Confirm Firebase rules are deployed.
- Confirm FormSubmit email activation is approved.

## Functional testing

- Test user login.
- Test every required field validation.
- Test salaried document checklist.
- Test self-employed document checklist.
- Test PDF upload below 10 MB.
- Test ZIP upload below 10 MB.
- Test upload rejection above 10 MB.
- Test final enquiry submit.
- Test thank-you page.
- Test admin login.
- Test dashboard table.
- Test application detail panel.
- Test reject flow.
- Test next-process flow.
- Test pending sync.

## Cross-device testing

- Submit from phone using mobile data.
- View from laptop using Wi-Fi.
- Submit from laptop.
- View from phone.
- Confirm records do not depend on browser local storage after Firebase is shared.

## Real estate testing

- Add sample property listing data.
- Test property enquiry form.
- Test property filters.
- Test EMI calculator.
- Test property visit request.
- Test admin follow-up status.

## Post-launch monitoring

- Check Firebase usage.
- Check failed submissions.
- Check pending sync count.
- Check FormSubmit delivery.
- Check Storage file growth.
- Review admin dashboard daily during early launch.
