# Real Estate Features Roadmap

These features can extend the loan portal into a useful real estate and property finance website.

## Property listing features

- Add property listing page for sale, rent, and lease properties.
- Add filters for city, area, budget, property type, bedrooms, plot size, and possession status.
- Add property detail page with photos, location, price, amenities, and contact form.
- Add enquiry button on every property listing.
- Add featured properties section on the home page.
- Add admin property management panel to add, edit, hide, and delete listings.

## Real estate finance features

- Add home loan eligibility calculator.
- Add EMI calculator for home loan, loan against property, and plot purchase.
- Add stamp duty and registration cost estimator by state.
- Add document checklist for home loan, plot loan, construction loan, and mortgage loan.
- Add balance transfer enquiry flow for existing home loans.
- Add property valuation request form.

## Customer workflow

- Allow users to choose `Loan enquiry`, `Property enquiry`, or `Loan plus property enquiry`.
- Connect property enquiry with loan requirement in one application.
- Add property visit booking request.
- Add preferred callback time and preferred locality.
- Add co-applicant details for home loan enquiries.
- Add builder/project name field for apartment finance.

## Admin workflow

- Add dashboard tab for loan enquiries.
- Add dashboard tab for property enquiries.
- Add dashboard tab for site visit requests.
- Add status options: New, Contacted, Visit scheduled, Documents pending, In process, Closed.
- Add notes field for admin follow-up.
- Add reminder date for next customer follow-up.

## Useful content pages

- Home buying guide.
- Documents required for property purchase.
- Home loan process guide.
- Loan against property guide.
- Real estate investment checklist.
- FAQ page for buyers, sellers, and borrowers.

## Future integrations

- Google Maps embed for property locations.
- WhatsApp click-to-chat for property enquiries.
- Image upload and Firebase Storage for property photos.
- Admin CSV export for property leads.
- Optional CRM integration for follow-up tracking.
